Como gerar o APK e Instalar

Quer enviar o arquivo .APK pronto para ele?

Como este é um aplicativo web profissional (PWA), você pode transformá-lo em um arquivo APK instalável em 1 minuto:

  1. Hospede este arquivo HTML gratuitamente no Netlify Drop ou GitHub Pages para ter um link web.
  2. Acesse o site gratuito pwabuilder.com (da Microsoft).
  3. Cole o link do seu site lá e clique em "Generate".
  4. O site vai criar o arquivo .APK pronto para você baixar e enviar para o WhatsApp do seu primo! Ele instala como qualquer aplicativo de loja.
💡 Alternativa Rápida (Sem APK): Se preferir, basta mandar o link direto do app para ele abrir no Chrome do celular, tocar nos 3 pontinhos e selecionar "Adicionar à tela inicial". Funciona exatamente igual a um app nativo, salvando os orçamentos e gerando PDFs!
